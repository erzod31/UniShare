# Problemas conocidos y bloqueos

DG-0018 / 0.6.24: el actualizador propio se implementa en Windows y Android y se verifica con
lanzadores falsos. El canal real publica 0.6.16; el candidato no está publicado. Falta aplicar una
actualización real en VM/dispositivo independiente. La extensión ZIP necesita publicación/identidad
de tienda para actualizar su binario. Esas dependencias no se declaran verificadas por las pruebas.
