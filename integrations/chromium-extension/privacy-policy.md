# Política de privacidad de la extensión UniShare para Microsoft Edge

Última actualización: 26 de septiembre de 2026.

## Finalidad y datos tratados

La extensión tiene una sola finalidad: guardar en UniShare la página que el usuario elige expresamente.
Al pulsar **Guardar pestaña**, puede tratar la URL, el título, la carpeta indicada y, si se selecciona
**Guardar también una copia offline**, el texto ya renderizado y hasta doce imágenes visibles que el
navegador permita leer.

## Destino y almacenamiento

La información se envía únicamente a la aplicación UniShare del mismo ordenador a través de la dirección
local `http://127.0.0.1`. La extensión no envía datos a UniShare, Microsoft ni otros terceros por Internet,
no usa analítica, publicidad, telemetría ni seguimiento. El puerto y la clave privada de conexión se
guardan en el almacenamiento local del perfil de Edge y sólo se usan para autenticar esa comunicación
local.

## Control y eliminación

El usuario decide cada guardado y puede desactivar la copia offline. Puede modificar o eliminar los
elementos desde UniShare. Puede borrar la configuración de la extensión eliminándola o limpiando sus
datos desde Edge. Desinstalar la extensión no elimina automáticamente la biblioteca local de UniShare.

## Conservación y terceros

La extensión no mantiene una base de datos remota ni comparte información con terceros. La conservación
de los elementos depende exclusivamente de la biblioteca local UniShare y de las copias de seguridad que
configure el usuario.

## Contacto

Para consultas de privacidad o soporte debe usarse el contacto del editor que figure en la ficha oficial
de UniShare en Microsoft Edge Add-ons.
